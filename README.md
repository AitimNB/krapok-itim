# krapok-itim

แอป PWA ถูกรวมให้รันจากไฟล์ ZIP ได้แล้ว

## การใช้งาน

เปิดหน้าเว็บไซต์ของโปรเจกต์ หรือรันแบบ local:

```bash
python3 -m http.server 8080
```

จากนั้นเข้า `http://localhost:8080`

ไฟล์ต้นฉบับอยู่ที่ `krapok_itim_pwa_v1.zip` และตัวเปิดแอปอยู่ที่ `index.html` เพื่อความสะดวกในการติดตั้ง PWA บน GitHub Pages
