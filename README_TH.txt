# กระปุกไอติม PWA 1.0

แอปจัดการเงินส่วนตัวและธุรกิจแบบเก็บข้อมูลในอุปกรณ์ (Local-only)

## คุณสมบัติ
- บันทึกรายรับพร้อมต้นทุนและเงินกันภาษี
- คำนวณกำไรและข้อเสนอแบ่งเงินบุญ/ภาระประจำ/เงินแม่/เงินส่วนตัว/เงินสำรอง
- ผู้ใช้ปรับยอดและกดยืนยันเอง
- บันทึกรายจ่ายหลายช่องทาง
- เก็บข้อมูลใน localStorage ของเบราว์เซอร์
- ส่งออกและนำเข้าไฟล์ JSON สำรอง
- PWA พร้อม service worker สำหรับเปิดออฟไลน์หลังโหลดครั้งแรก

## ข้อจำกัดสำคัญ
- ไม่มีการเชื่อมบัญชีธนาคารหรือโอนเงินจริง
- ข้อมูลไม่ได้ sync ข้ามอุปกรณ์
- การล้างข้อมูลเว็บไซต์/เบราว์เซอร์อาจลบข้อมูลแอปได้ โปรด export backup เป็นประจำ
- PWA ต้องเปิดผ่าน HTTPS (หรือ localhost) จึงจะติดตั้งและใช้ service worker ได้
- ไฟล์นี้เป็นชุดต้นแบบที่ต้องนำไปวางบน HTTPS hosting ก่อนติดตั้งจาก Chrome Android

## ติดตั้งบน Android
1. อัปโหลดไฟล์ทั้งหมดในชุดนี้ไปยัง HTTPS hosting ที่คุณควบคุม
2. เปิด URL ของแอปด้วย Chrome บน Android
3. เลือกเมนู Chrome (⋮) > Install app หรือ Add to Home screen
4. กดติดตั้ง แล้วเปิดจากไอคอนบนหน้าจอ

## สำรองข้อมูล
ในหน้า ภาพรวม > ดาวน์โหลดไฟล์สำรอง ควรสำรองอย่างสม่ำเสมอและเก็บไฟล์ไว้นอกอุปกรณ์ด้วย
